# 개인별 학습 순위 v3 (선택적 실험)

2026-10-05. `/ml/learning-fit` 요청의 `modelVersion`을 `concept-learning-v3`로
지정하면 사용한다. v1/v2의 계약·정렬과 `/ml/rank`는 유지한다. Backend와
Frontend의 현재 v2 호출은 바꾸지 않았다. 앱 기본 추천에 자동 적용되지 않는다.

## 무엇을 계산하는가

책의 개념 집합 C와 검토된 그래프의 모든 선수개념 집합 P는 사용자와 무관하다.
책 안에서 등장하는 선수개념도 P에서 제외하지 않는다. 등장 순서나 목차 존재만으로
충분히 가르친다고 보지 않는다. 기존 v2의 근거·읽기 체크리스트를 그대로 제공한다.
책 본문의 절대 난이도나 입문/중급/고급을 새로 추정하는 알고리즘이 아니다.

선택한 능력의 객관식 관찰 집합 O와 한 번이라도 오답이 관찰된 개념 집합 W를 사용한다.
다른 능력의 응답은 섞지 않는다. 미평가를 오답이나 새 학습 목표로 간주하지 않는다.

- 관찰된 선수개념 오답률 = P∩O의 각 개념에 대해 `(응답 수-정답 수)/응답 수`를
  계산한 뒤 개념별 동일 비중으로 평균. 관찰이 없으면 null.
- 선수 진단 범위 = `|P∩O|/|P|`. P가 없으면 null.
- 복습 개념 포괄률 = `|C∩W|/|W|`. W가 없으면 null.
- 복습 개념 비중 = `|C∩W|/|C|`.
- 전부 정답이었던 책 개념 비율도 반환하지만 순위에 쓰지 않는다. 정답 관찰은
  숙달 확정이 아니며, 그 역수를 새 학습 가치로 쓰면 미평가 책을 우대하게 된다.

비율은 모두 0~1이다. 가중합·점수 경계값은 없다. 다음 기준을 앞에서부터 비교한다.

1. 선수관계가 있는 후보 우선. 관계가 없는 책을 쉬운 책으로 오인하지 않는다.
2. 기존 준비도 상태: ready-to-explore → check-first → foundation-gap.
3. 관찰된 선수개념 오답률이 낮은 순.
4. 선수 진단 범위가 높은 순.
5. 복습 개념 포괄률이 높은 순.
6. 복습 개념 비중이 높은 순.

이는 검증된 교육학적 최적 순서가 아닌 초기 정책이다. 특히 미평가가 남은 책과
복습 필요가 확인된 책의 우선순위, 좁은 책과 넓은 책의 선호는 사람이 평가해야 한다.
선수관계가 없는 진짜 기초서도 뒤로 갈 수 있다. 그래프 완성도를 난이도로 해석하지 않는다.
오답률 null은 내부 정렬에서 1로 놓되 응답에는 null로 유지하고 진단 범위를 함께 비교한다.
정책의 단일 원본은 `learning_order.py`의 `POLICY`/`CRITERIA`이며 응답에 버전을 반환한다.

정렬은 정확한 유리수로 비교한다. 동일 기준이면 같은 `rankGroup`, 전체 후보 기준
`tieCount`를 반환한다. `rank`와 bookId는 표시 순서일 뿐 동순위 안의 우열이 아니다.
coveredConcepts는 v3에서 중복 제거한다. 알 수 없는 개념·중복 bookId는 거부한다.
v1/v2의 중복 개념 거부 동작은 유지한다. 일부 목차 누락은 복구하지 못한다.

## 사람이 평가할 것

CSV 42행(7권×6시나리오)의 점수·이유·평가자·날짜는 비어 있다. 순위 열은 숨겼다.
평가자는 같은 snapshot의 개념 연결과 원출처 목차, 시나리오 응답을 함께 확인한다.
다음 책으로의 적합도를 1(선수 보완이 우선), 2(상당한 보완 필요), 3(조건부 적합),
4(대체로 적합), 5(우선 추천)로 기록한다. 판단 근거가 없으면 빈칸과 이유를 남긴다.
적어도 독립 평가자 둘이 기록하고 불일치 이유를 검토한다. 문항 품질·목차 오탐·누락도
별도로 점검한다. 테스트를 통과했다는 이유로 평가 점수를 채우지 않는다.
평가 뒤 동일 후보 집합에서 사람의 선호와 v2/v3의 순서 일치도를 비교하고, 동순위는
억지로 우열을 만들지 않는다. 실제 사용자 학습 효과는 별도 후속 평가가 필요하다.

자동 검증은 사용자별 순위 반전, 같은 상태 내 오답률 비교, 중복 불변성,
정답 증가 시 동일 책 관찰 부담 비증가, 미평가 비우대, 동순위/limit,
다른 능력 격리, 이전 버전 호환성, 입력 해시와 평가 파일 보존을 다룬다.

평가표를 채운 뒤 검증·집계하는 명령은 [사람 평가 안내](learning-order-human-evaluation.md)에 있습니다.
새 비교 출력은 v2 계약으로, comparison.json 해시와 v2의 의미상 동순위를 함께 보존합니다.
기존 v1 평가 자료는 덮어쓰지 말고 새 폴더로 생성하세요.
